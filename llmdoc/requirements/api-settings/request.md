# 网页 API 配置

日期：2026-09-21；需求版本：1。

用户要求：「提供api接口网页配置能力」。在现有设置页提供应用实际使用的 Tripo 与说明书 AI 的 API 地址、密钥、模型等配置入口，能保存并说明生效状态，覆盖刷新/重启后的持久化、输入错误和配置失败反馈。基于当前适配器，不凭空声称支持新的供应商协议。

最新用户请求明确替代旧方案中「网页不输入 API 密钥、仅只读配置状态」的范围限制。本批允许增加受已有管理员认证和 CSRF 保护的设置读写接口。密钥保留在服务端；读取接口仅返回是否已配置等状态，不回显完整密钥，不写入浏览器持久存储、日志或项目证据。

默认只保存用户输入的配置，不触发收费生成或上传用户资料；本地模拟服务验证生效，真实供应商调用仍须另有授权。明确环境变量、配置文件、网页配置的优先级及在途任务边界，不破坏既有费用确认、幂等、数据归属和发布不变量。

按 PM → UI → RD → QA 完成产品实现与独立验收，本目录记录本批结果。保留 interaction-a 以及用户已有的暂存/未暂存改动，不提交、推送或公网发布。
