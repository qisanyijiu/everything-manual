# 前端视觉更新（2026-09-19）

用户在运行样例后要求美化前端。本轮只调整 React 界面、样式与对应的前端测试，没有变更后端、数据库或供应商调用。

## 设计与交互

- 使用暖白底、墨绿导航、赤陶橙主操作，统一按钮、输入框、状态标签、卡片、间距和字号。主题固定为浅色，不再自动跟随系统深色；这是本次视觉更新对旧基础亮度约定的调整。
- 桌面使用左侧导航，手机使用底部导航，手机登出保留在顶栏。保留键盘焦点、跳到主要内容、抽屉焦点恢复以及减少动效支持。
- 资料库增加本地 SVG 插画和物品图标，计数只代表已加载数据，没有增加模拟业务数据或外部图片/字体依赖。
- 资料库和物品概览的「打开说明书」接入已存在的发布版本列表；未发布物品走该页面的真实空态，避免早期“阅读器未交付”的错误提示。
- 阅读器的版本标识、模型 revision 和 manifest 哈希保留在可展开的版本信息里；3D、部件、步骤和 PDF 功能不变。物品原件的完整 SHA256 保留在可展开的校验信息里。
- 登录、物品表单、详情、任务中心、设置、版本列表和阅读器共享视觉样式。实现入口为 `apps/web/src/theme.css`，加载在原有功能样式之后。

## 验证范围

- 前端 production build（含 TypeScript 检查）、ESLint、130 项 Vitest 通过。
- 使用真实 Rust 样例后端和浏览器检查首页、发布版本列表、3D 阅读器、PDF 页码联动、手机抽屉及焦点恢复、新建表单、登录页面。
- 检查 375、768、1024、1280、1440 像素宽度的首页，无页面横向溢出；桌面与手机截图已在本次会话中目视核对。
- 更新旧 E2E 中“阅读器未交付”与禁用说明行的过时断言，并适配折叠的版本信息；本轮未执行完整 Playwright 套件，也不改变原有 T22/T23 的 QA 状态。
