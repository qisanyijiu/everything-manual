# 视觉风格优化 PRD

状态：planned，产品方案已输出；UI 修订 1 于 2026-10-04 冻结（VS-01 设计基线，见 §9），待实施。修订：1。更新日期：2026-10-04。反馈范围：第 3 项。建议优先级：P1。

## 1. 需求依据与目标

依据[用户请求与范围](request.md)及[原反馈第三节](../../../artifacts/ui-feedback-20261004/source/UI改稿反馈.md)。目标是让“万物说明书”形成可识别的技术手册视觉：内容与产品模型居于中心，以网格、编号、细线和清晰的文字层级表达专业性。复古感来自档案与说明书结构，未来感来自可交互模型和精确标注。

现有暖白、墨绿、橙色主题已有一致性，但大圆角面板、装饰插画及部分小字号需要重新整理。源码依据：[theme.css](../../../apps/web/src/theme.css)、[AppShell](../../../apps/web/src/features/shell/AppShell.tsx)、[阅读器](../../../apps/web/src/features/manual/ReleaseReaderPage.tsx)。这是视觉改版设计，不是对现有所有页面存在渐变或发光的断言。

交付成功以第 4 节验收为准。辅助评估建议邀请 5 位目标用户查看资料库、阅读器、上传确认三页，每页 5 秒后回答“页面用途和主要操作”；至少 4 人正确识别。该数值为拟定研究目标，当前无基线、无实际测试结果，不代替功能与可达性验收。

## 2. 范围与非目标

本期覆盖应用外壳、登录、资料库、物品详情、上传/准备/确认、任务列表/详情/结果、复核、版本列表、原件阅读、3D 阅读器、设置及新导出的独立 HTML 阅读器。只改视觉与必要的语义结构，复用当前真实业务能力。

不重构第 2 项的产品流程，不扩充说明书库、不预制模型，不隐藏费用/隐私确认、不改复核与发布门禁。本期不新增社区入口、联网字体、主题切换、3D 几何处理或付费调用。历史导出的 HTML 和发布快照不回写；改版后的新导出采用新版展示样式。

## 5. 非功能与数据约束

- 沿用 React、现有 CSS、R3F 和 Rust 单二进制；不修改供应商、预算、认证、发布或存储合同。设计变量集中维护，避免 `theme.css` 与功能样式反复覆盖形成页面例外。
- 网格用轻量 CSS 或已有本地矢量表达；纯色层次足够时不加纹理位图。装饰元素 `aria-hidden` 且不接受指针事件。PDF 原页、照片、GLB 材质与模型几何不做复古滤镜。
- 不新增追踪服务。上文 5 秒识别测试由研究记录完成，不收集用户说明书内容；截图使用既有授权样本或 fixture。
- 控件尺寸、对比度和产物体积是本项目验收指标；任何运行结果须由实施阶段记录，不能引用历史测试数作为本次通过依据。

## 6. UI 交互设计

### 6.1 视觉规格

以下为 v1 设计参数；2026-10-04 VS-01 已用样页校正（见 §9），可执行取值集中在 [design/vs-01/tokens.css](design/vs-01/tokens.css)，改动时须同步本表、tokens 与验收截图。

| 项目 | 规格与用途 |
| --- | --- |
| 纸面与正文 | 页面 `#F4F1E8`、内容 `#FFFEF9`、墨色 `#232620`、辅助字 `#62665D`；正文优先纯色背景 |
| 强调与状态 | 主操作 `#A63F21` 配白字，悬停 `#8F3518`、按下 `#7A2C12`；选中背景 `#EEE2CF` 配墨色；成功 `#2F6248`、警示 `#805D12`、错误 `#A12F2F` 配内容底，徽标软底可用 `#E9EFE6`/`#F4E8D2`/`#F6E3DE`；状态同时有名称或图标 |
| 线条与网格 | 装饰分隔 `#D5D1C5`，交互控件边界 `#7D8176`；1px 实线。低对比 24px 网格（墨色 6%，`rgba(35,38,32,.06)`）仅限模型空白区/章节装饰区，不铺在密集正文背后 |
| 字体 | 中文与正文沿用系统无衬线（栈见 tokens.css `--font-sans`）；型号、章节号、页码用系统等宽字（`--font-mono`）；不复制参考图的展示字体；不远程加载字体 |
| 文字层级 | 桌面页标题 28/36px，手机 24/32px；章节标题 18/26px；正文 14/22px，阅读正文建议 16/26px；辅助和编号最低 12/18px |
| 布局 | 8px 主间距系统，可用 4px 微调；桌面 12 列、24px 列距，正文容器最大 1440px；手机 4 列、16px 外边距；说明正文推荐不超过 72 个字符宽（`--layout-measure: 72ch`） |
| 组件形状 | 面板 2px 圆角，输入/按钮 4px；标签为矩形编号牌（2px 内圆角，非胶囊）；头像、热点编号等圆形有明确语义时保留。正文面板无阴影，浮层可用一层轻阴影 |
| 操作反馈 | 主按钮实底，次按钮描边，链接下划线或清晰图标；焦点 3px `#A63F21`、外偏移 3px；通常过渡取 140ms（范围 120～180ms），减少动效模式取消；禁用不只降透明度：软底 `#EDEAE0` + 辅助字色，禁用原因常驻可见 |

参考图的取舍见[来源归档](../../../artifacts/ui-feedback-20261004/README.md)。章节号是导航辅助，不伪造产品规格；版本/型号/页码来自真实数据；产品名称统一为“万物说明书”。

### 6.2 页面与布局

既有路由以 [App.tsx](../../../apps/web/src/App.tsx) 为准；本项不新增业务路由。

| 页面组 | 主要构图 | 窄屏规则 |
| --- | --- | --- |
| 应用外壳与登录 | 导航像目录页；品牌、当前章节、账户分区；登录使用短说明与单列表单 | 沿用移动导航；登录单列，装饰让位于输入与提交 |
| 资料库与物品概览 | 标题/实际计数 → 搜索 → 有序档案行；详情是品牌/型号规格栏与“原件、3D、版本”章节 | 档案行按名称、型号、状态、动作堆叠；不变成横向宽表格 |
| 上传、准备、确认 | 分节编号与同宽表单；费用、数据发送范围及确认在连续主内容中 | 单列按原顺序滚动，底栏避让键盘与确认按钮 |
| 任务与生成结果 | 列表使用状态列；详情将阶段、结果和恢复动作分区 | 用章节块替代横向时间轴；保留失败的具体阶段和动作 |
| 复核和 3D 阅读器 | 标题/型号/版本 → 部件目录、中央模型、步骤/原件；工具条固定在模型容器内 | ≥1280px 三栏；768～1279px 保留现有侧面板标签；<768px 模型加单抽屉。复核几何操作沿用现有桌面限制 |
| 原件、版本列表、设置 | 原件周围使用页码/来源栏；版本和设置使用规格分区 | 原文支持现有缩放/滚动；技术设置表单可换行，不为视觉目标隐藏必要说明 |
| 新导出独立 HTML | 阅读器相同的纸面、编号、步骤和工具按钮 | 与现有独立查看逻辑兼容；无登录/社区占位操作 |

## 8. 假设与决策

| 结论 | 原因、影响与状态 |
