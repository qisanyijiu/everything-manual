# 组件全状态说明（VS-01 设计基线 v1）

日期：2026-10-04。状态：冻结（对应视觉 PRD 修订 1，UI 修订 1）。用途：VS-02～VS-04 实现与 VS-05 验收的组件状态对照基线；所有取值引用同目录 [tokens.css](tokens.css)，用法示例见 [library-specimen.html](library-specimen.html)、[reader-specimen.html](reader-specimen.html)、[forms-specimen.html](forms-specimen.html)。

约定与总则：

- 状态命名沿用现有实现：`默认 / 悬停 / 按下 / 焦点 / 禁用 / 进行中`（按钮），`默认 / 悬停 / 焦点 / 错误 / 禁用 / 只读`（输入）。
- 禁用态一律「软底 `--color-surface-soft` + 辅助字色 `--color-ink-muted`」，不整体降透明度；禁用原因必须常驻可见（文本或 `aria-describedby` 关联），不依赖悬停提示。
- 状态永远有文字或图标说明，不用颜色单独表达（成功/警示/错误/未知均同）。
- 焦点环：`--focus-ring-width` 3px、`--focus-ring-offset` 3px、色 `--focus-ring-color`；深色浮层用 `--focus-ring-color-inverse`。焦点样式不得被 `overflow: hidden` 剪裁。
- 过渡只使用 `--duration-*`（120/140/180ms 档），减少动效偏好下由 tokens 置 0；过渡不得改变布局或触发请求。
- 所有可点击元素窄屏（<768px）触控范围 ≥44×44px（`--control-height-touch`）；桌面次要工具按钮可用 32px 紧凑规格。

## 1. 导航项（侧栏目录 / 顶栏 / 移动底栏）

| 状态 | 表现（token） | 语义与可访问性 | 场景 |
| --- | --- | --- | --- |
| 默认 | 透明底、墨色文字、图标同色 | 真实链接 `<a>`；名称与图标全站一致 | 侧栏「资料库 / 任务中心 / 设置」 |
| 悬停 | 底 `--color-surface-hover` | 不改变文字位置 | 指针经过 |
| 焦点 | 3px 焦点环 + 3px 偏移 | 键盘 Tab 可达；顺序与视觉顺序一致 | 键盘导航 |
| 选中 | 左 3px `--color-accent` 边线 + 底 `--color-selected` + 文字加粗 | `aria-current="page"`；三重表达（边线/底色/文字），不只靠颜色 | 当前页面；资料库在物品相关路由保持选中 |
| 进行中（任务入口） | 文本计数「N 进行中」；读取失败时显示「任务状态暂不可用」 | 计数来自有界汇总，失败不用 0 冒充 | 顶栏任务入口 |

对应 UI-VS-001（AC-003：同一会话各页名称/图标一致，路由可刷新）。

## 2. 按钮

| 类别 | 默认 | 悬停 | 按下 | 焦点 | 禁用 | 进行中 |
| --- | --- | --- | --- | --- | --- | --- |
| 主按钮（实底） | 底 `--color-accent`、白字 | `--color-accent-hover` | `--color-accent-active` | 焦点环 | 软底 + 辅助字色 + 原因常驻 | 文案改「正在保存…」等 + `aria-busy="true"`，保持禁用 |
| 次按钮（描边） | 内容底 + `--color-line-control` 边界 | 底 `--color-surface-hover` | 同悬停加深 | 焦点环 | 同上 | 同上 |
| 链接式 | `--color-accent` 下划线 | 下划线保持、颜色不变 | 同悬停 | 焦点环 | 不适用（不提供禁用链接） | 少见；用文案表达 |
| 图标按钮 | 图标 + 可访问名称（`aria-label`） | 底 `--color-surface-hover` | 同悬停 | 焦点环 | 软底 + 原因常驻 | 同上 |

- 同一操作区域只允许一种主按钮样式；加载中不改变按钮宽度（避免布局跳动）。
- 触控：窄屏全部 ≥44×44px；主操作在桌面也保持 ≥40px 高。
- 对应 UI-VS-001、UI-VS-004。

## 3. 输入与选择

| 控件 | 状态清单 | 语义与可访问性 | 备注 |
| --- | --- | --- | --- |
| 文本 / 密码 | 默认 / 悬停 / 焦点 / 错误 / 禁用 | `<label for>`；错误 `aria-invalid` + `aria-describedby`；密码 `autocomplete="current-password"`，无默认值 | 边界 `--color-line-control`（≥3:1）；焦点环 + 边框强调 |
| 搜索 | 默认 / 焦点 / 错误（超 200 字符） | 错误 `role="alert"`，贴近字段；搜索词入 URL | 计数与范围提示常驻 |
| 下拉选择 | 默认 / 焦点 / 禁用 | 用原生 `<select>`；被禁用时页内说明原因（如「先停止当前准备」） | 不改宽度布局 |
| 复选框 / 单选框 | 默认 / 选中 / 焦点 / 禁用 | 标签行整体可点，≥44px 高；分组用 `fieldset/legend` | 选中不只靠颜色：对勾/圆点 + 文字 |
| 文件上传 | 默认 / 已选择 / 上传中 / 失败 | 校验说明（类型/大小）常驻；失败给「重新上传」 | 上传中按钮禁用并显示进度文案 |
| 密钥（设置） | 默认 / 焦点 / 改密 / 禁用 | 只做瞬时输入：不回显、不缓存；`autocomplete="new-password"` | 保存不等于验证连接 |

对应 UI-VS-001（通用）、UI-VS-004（表单与设置）。

## 4. 标签、编号牌与状态徽标

| 组件 | 状态 | 表现 | 语义 |
| --- | --- | --- | --- |
| 编号牌（矩形） | 中性 / 强调 / 失效 | `--radius-plate` 2px、1px 实线；`--font-size-aux` | 章节号、部件编号、页码；等宽字体 |
| 物品状态牌 | 使用中 / 已归档 | 中性边界；强调用 `--color-selected` 底 | 与档案行操作并列，不替代文字 |
| 结果状态牌 | 成功 / 警示 / 错误 | `--color-success/-warning/-danger` 文字 + 软底（可选） | 始终带文字 |
| 任务状态徽标 | 9 种状态（队列/本地/供应商/人工/未知/完成/失败/取消）+ 未知原值 | 圆点 + 文本；`status-tag--unknown` 用警示色 | 未知状态原样显示，不猜测；不出现百分比 |

状态软底仅作辅助，不允许成为唯一区分手段。对应 UI-VS-002（资料状态）、UI-VS-003（热点标签）、UI-VS-004（任务状态）。

## 5. 档案行（资料库行 / 发布版本行）

| 状态 | 表现 | 语义 |
| --- | --- | --- |
| 默认 | 名称 + 品牌/型号（等宽）+ 处理状态 + 更新时间 + 操作 | 名称进详情；状态与版本来自真实摘要 |
| 悬停 | 行底 `--color-surface-hover` | 纯视觉提示，不改变内容 |
| 无封面 | 本地线性物品图标（当前用立方体图标） | 不生成假封面、不用外链图片 |
| 长型号 | 型号列 `overflow-wrap: anywhere`，允许换行 | 不截断、不省略到不可辨 |
| 状态不可读 | 「处理状态暂不可用」+「重新读取处理状态」按钮 | 失败不显示 0 条或空白 |
| 已归档 | 状态牌「已归档」+ 归档时间 | 归档不删除既有资料入口 |
| 分页行 | 「加载更多」/「正在加载…」/「已到末尾」 | 只对已加载范围计数，不冒充全库总量 |

窄屏按名称 → 型号 → 状态 → 操作纵向堆叠，不横向滚动。对应 UI-VS-002（AC-004）。

## 6. 热点标记与部件条目（阅读器 / 复核）

| 状态 | 3D 标记 | 列表条目 | 语义 |
| --- | --- | --- | --- |
| 已确认（confirmed） | 实心编号圆（`--color-accent` + 白字） | 状态牌「热点 N」 | 进入发布版；3D 与列表双向联动 |
| 候选（candidate） | 虚线空心环 + 问号 | 状态牌「候选（待复核）」 | 与已确认明显区分；确认前不入发布版 |
| 选中（selected） | 额外 3px 焦点环（不闪烁） | 底 `--color-selected` + 边框强调 + `aria-current` | 选择来源可以是列表、热点或步骤 |
| 无热点 | 模型区不画标记 | 状态牌「无热点」+「暂无定位」文字 | 不画装饰连线冒充真实标注 |
| 仅文本条目（textOnly） | 不显示 | 状态牌「仅文本条目」，发布说明列出 | 发布时保留并明显标识 |
| 失效（stale） | 不显示 | 状态牌「失效（stale）」 | 模型更新后定位失效；不静默转为已确认 |

键盘：列表项与热点选择均为按钮，Tab/回车可达；3D 视角操作有按钮等效入口；列表是热点的文字替代。对应 UI-VS-003（AC-005/006/009/010）。

## 7. 骨架屏

| 状态 | 表现 | 语义 |
| --- | --- | --- |
| 按分区占位 | 列表骨架（身份/状态/时间行）、详情骨架、3D 骨架；标签文案（如「正在查找物品…」） | `role="status"`；不阻塞页内其他可用区块 |
| 与真实布局一致 | 骨架宽度按真实内容比例（80/60/40%） | 避免加载后大幅跳动 |

对应 UI-VS-001。

## 8. 空态

| 场景 | 标题与动作 | 语义 |
| --- | --- | --- |
| 空库 | 「还没有物品」+ 新建物品 | 真实零条 |
| 搜索无结果 | 「当前范围没有匹配物品」+ 清除搜索 | 与空库区分 |
| 归档范围为空 | 「没有已归档的物品」+ 查看使用中的物品 | 保留范围说明 |
| 无原件 / 无照片 | 说明 + 去对应步骤的链接 | 链接到可修复步骤 |
| 阅读器无部件/步骤 | 「该发布版本没有部件列表。」 | 空不是错误 |
| 无模型 | 「该草稿没有可用的模型版本…部件、步骤与原文仍可阅读。」 | 文字路径仍可用 |

对应 UI-VS-002、UI-VS-003。

## 9. 抽屉 / 中部侧栏标签页 / 对话框

| 形态 | 状态 | 语义与键盘 |
| --- | --- | --- |
| 抽屉（窄屏） | 关闭 / 打开 / 关闭中 | `aria-haspopup="dialog"`；Esc 关闭；关闭后焦点回到触发按钮；同一时刻只开一个 |
| 中部侧栏标签页 | 选中 / 未选中 / 焦点 | `role="tablist/tab/tabpanel"`；左右方向键 + Home/End 切换；`aria-selected` |
| 对话框（离开保护等） | 打开 / 关闭 | 焦点进入对话框并限制在内部；Esc 关闭；`::backdrop` 遮罩；确认/丢弃动作文字明确 |

对应 UI-VS-001（组件）、UI-VS-003（阅读器面板）、UI-VS-004（离开保护）。

## 10. 通知

| 类别 | 行为 | 语义 |
| --- | --- | --- |
| 成功（status） | 自动消失（约 6 秒） | `role="status"`，不打断朗读 |
| 失败 / 需处理（alert） | 保留到用户关闭；可带诊断 requestId 与「查看」动作 | `role="alert"`；同一错误同时在对应区块内联保留 |
| 计数与去重 | 多次操作各自成条，可单条关闭或全部关闭 | 通知不承载唯一错误信息 |

对应 UI-VS-001、UI-VS-004。

## 11. 表单错误（摘要 + 字段级）

| 状态 | 表现 | 语义 |
| --- | --- | --- |
| 提交前 | 必填为空置灰主操作 + 原因常驻 | 原因与按钮 `aria-describedby` 关联 |
| 服务端 422 | 顶部摘要（可聚焦）+ 每字段 `aria-invalid` + `aria-describedby`；焦点移到第一个错误字段 | 摘要列出可跳转的错误项 |
| 412/428 冲突 | 冲突提示卡：当前版本 + 「刷新后重试」；刷新前禁用提交；输入保留 | 不自动覆盖、不丢表单内容 |
| 提交结果未知 | 警示卡 + 「核对…结果」动作 | 未收到响应不代表未创建，不自动重复提交 |

对应 UI-VS-004（AC-007/008）。

## 12. 分页与加载更多

| 状态 | 表现 | 语义 |
| --- | --- | --- |
| 可加载 | 「加载更多」按钮（≥44px） | 游标写入 URL，刷新/后退保留 |
| 加载中 | 按钮禁用 + 文案「正在加载…」 | 不改变列表高度 |
| 到末尾 | 「已显示 N 件物品，当前分页已到末尾。」 | 只对已加载范围计数 |
| 游标失效（422） | 「列表条件已变化，请回到开头」+ 回开头按钮 | 不猜测、不静默重置 |

对应 UI-VS-002。

## 13. 进度与阶段（准备 / 任务）

| 状态 | 表现 | 语义 |
| --- | --- | --- |
| 准备中 | `<progress>` + 「已处理 43 / 68 页」+ 缺页编号牌 | 为真实页计数；缺页可补跑，已保存页不重复 |
| 停顿/冲突 | 「记录已更新，请重新读取进度」+ 重新读取 | 进度不覆盖服务器新记录 |
| 任务阶段 | 阶段名（真实 kind 标签）+ 状态标签 + 恢复动作 | 逐阶段展示，不用百分比、不给预计时间 |
| 结果未知 | 「结果未知（等待对账）」+「核对供应商账户」 | 不提供盲目重试；后续购买暂停 |
| 完成 | 「已完成（可复核草稿已产出，尚未发布）」 | 生成完成不等于已发布 |
| 退避中 | 「退避重试中」且不提供「立即重试」 | 不打断退避序列 |

对应 UI-VS-004。

## 14. 离开保护对话框

| 状态 | 表现 | 语义 |
| --- | --- | --- |
| 触发 | 未保存修改 / 准备进行中 / 提交在途离开时弹出 | 文案说明「丢弃什么、保留什么、在途请求可能已完成」 |
| 动作 | 「留在本页」（默认焦点）/「丢弃修改并离开」 | Esc 关闭视为留在本页；焦点回到触发处 |
| 设置页变体 | 修改未保存离开时提示丢弃范围 | 不静默保存 |

对应 UI-VS-004。

## 15. 键盘与焦点总合同

| 能力 | 要求 |
| --- | --- |
| 跳转主内容 | 每页首个 Tab 目标为「跳到主要内容」链接（聚焦后可见） |
| Tab 顺序 | 与视觉顺序一致；不使用正 `tabindex` |
| 面板标签页 | 左右方向键 + Home/End；`aria-selected` 与 `tabindex` 同步 |
| 抽屉 / 对话框 | Esc 关闭；关闭后焦点回到触发按钮 |
| 阅读器 | 部件/步骤/热点/翻页/视角全部可键盘操作；列表是 3D 的文字替代 |
| 焦点可见 | 全部焦点样式用 3px 焦点环；不被剪裁 |
| 减少动效 | `--duration-*` 置 0；取消相机动画与非必要过渡；状态变化仍即时可读 |

对应 UI-VS-001、UI-VS-003（AC-009）。
