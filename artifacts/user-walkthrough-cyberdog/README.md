# 机器狗（CyberDog 2）用户全流程走查

2026-10-04，真实浏览器（`walk.mjs`），只通过界面点击，从登录到打开已发布说明书。共 14 张截图，每张对应一个用户需要停下来看或操作的界面；全程约 10 分钟（其中生成约 6 分钟，用户可离开）。

| 1 | `01-login.png` | 输入管理员密码并登录 |

| 3 | `03-item-form.png` | 填写名称与型号，点「创建并继续」 |

## 复杂度结论

- 用户必须主动操作的点击约 20 次，集中在 5 步导入向导（物品 → 说明书 → 视图 → 准备 → 确认）和复核发布。
- 走查前，复核页需要逐条确认约 100 条 AI 提取的文字事实才能发布，这一步远超 15 张截图的预算；已加「确认全部 N 条文字事实」批量按钮，与已有的「确认全部候选热点」对齐。
- 仍可简化：「准备」步骤（浏览器逐页制作页图并封存）对用户没有决策内容，可以在绑定说明书后自动完成；模型复核的两个声明按钮可合并为一个。
